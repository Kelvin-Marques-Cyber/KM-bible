BÍBLIA REFORMADA 0.5.3 — PACOTE COMPLETO (INSTALAÇÃO LIMPA)
=======================================================

Este arquivo ZIP JÁ CONTÉM o código-fonte completo da 0.5.3.
Não exige instalar 0.5.0, 0.5.1 ou 0.5.2 antes. Inclui:
- Correções da visualização 3D da versão 0.5.2.
- Correção radial da galáxia de referências cruzadas 0.5.3.
- Biblioteca com botão “Importar ARA” ou “Ler Bíblia ARA” conforme instalação.
- Código para importar módulos .biblepkg, sem necessidade de instalar patches antigos.

IMPORTANTE: este ZIP não é um APK pronto. O build Android ainda não foi validado
neste ambiente; compile e teste no seu aparelho.

INSTALAÇÃO A PARTIR DO ZERO (openSUSE)
------------------------------------
mkdir -p ~/Documentos/biblia-reformada-053
unzip -o ~/Downloads/Biblia-Reformada-0.5.3-COMPLETA-publica.zip -d ~/Documentos/biblia-reformada-053
cd ~/Documentos/biblia-reformada-053
export JAVA_HOME=/usr/lib64/jvm/java-17-openjdk
export PATH="$JAVA_HOME/bin:$PATH"
flutter config --jdk-dir="$JAVA_HOME"
flutter pub get
flutter build apk --release --target-platform android-arm64 --no-pub

APK: build/app/outputs/flutter-apk/app-release.apk
Verifique a assinatura antes de atualizar uma instalação anterior.

Nota: contém a raiz do projeto diretamente (android/, lib/, assets/, etc.),
sem a subpasta biblia-reformada/ dentro do ZIP. Não extraia dentro de uma
pasta de projeto existente para evitar misturar versões.

VERSÃO PÚBLICA: a ARA NÃO acompanha o pacote por direitos autorais.
Cada usuário com acesso autorizado pode importar um módulo .biblepkg na
Biblioteca. O utilitário scripts/convert_ara_pdf_pessoal.py pode converter
localmente o PDF específico da ARA ao formato pessoal (requer Python e PyMuPDF),
mas não funciona genericamente para todos os PDFs.

VERSÃO PESSOAL: inclui o módulo ARA fornecido pelo próprio usuário. Após
instalação limpa, o app tenta importá-lo automaticamente na primeira abertura.
NÃO compartilhe APKs ou o código-fonte da versão pessoal com outras pessoas.
